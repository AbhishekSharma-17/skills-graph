## Installation

```bash
npm install d3
# or
yarn add d3
# or
pnpm add d3
```

CDN: `<script src="https://cdn.jsdelivr.net/npm/d3@7"></script>`

ESM: `import * as d3 from "https://cdn.jsdelivr.net/npm/d3@7/+esm";`
