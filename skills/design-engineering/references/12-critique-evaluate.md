# Critique & Evaluation -- Reference Router

Use these references to evaluate designs at different levels of detail. Start with Design Critique for a comprehensive review; use individual references for focused analysis.

## Sub-References

| Reference | File | Read When |
|-----------|------|-----------|
| **Design Critique** | `references/critique-evaluate/design-critique.md` | Full design review, comprehensive evaluation, "critique this", "review this" |
| **Heuristics Scoring** | `references/critique-evaluate/heuristics-scoring.md` | Nielsen's 10 heuristics, usability scoring, quantitative evaluation |
| **Personas** | `references/critique-evaluate/personas.md` | User testing, persona-based review, "test as different users" |
| **Cognitive Load** | `references/critique-evaluate/cognitive-load.md` | Mental effort assessment, information overload, decision complexity |
| **Technical Audit** | `references/critique-evaluate/technical-audit.md` | Accessibility, performance, theming, responsive, code quality checks |

## When to Use What

- **Full review needed** -- Start with Design Critique. It incorporates all other references automatically.
- **Quantitative score needed** -- Use Heuristics Scoring for a 0-40 numeric assessment.
- **Specific user perspective** -- Use Personas to test through the eyes of distinct archetypes.
- **Interface feels overwhelming** -- Use Cognitive Load to diagnose information overload.
- **Code-level quality check** -- Use Technical Audit for accessibility, performance, and implementation issues.

## Typical Flow

1. Run **Design Critique** for the full picture
2. Deep-dive into specific areas using individual references
3. Use findings to prioritize fixes
4. Re-run critique after changes to measure improvement
