## SaaS / Tech Startup

**Key prompt elements:**
- Dark backgrounds (#0f172a family)
- Blue/purple accent colors
- Spring animations (snappy feel)
- Product screenshots with device mockups
- Metrics (users, uptime, ratings)
- "Start free trial" CTA pattern

**Scene pattern:**
```
Hook: "Still doing [pain point] manually?"
Reveal: Product name + logo (spring bounce)
Features: 3 features with screenshots (split layout)
Proof: Metric cards (counting animation)
CTA: "Try it free" on brand color background
```

## E-commerce / DTC Brand

**Key prompt elements:**
- Clean white or brand-colored backgrounds
- Product photography (large, centered)
- Price display (bold, clear)
- Urgency elements (sale badges, countdown)
- "Shop Now" CTA with URL

**Scene pattern:**
```
Hook: Product hero shot (spring scale)
Features: 2-3 USPs with icons
Social proof: Reviews/ratings
CTA: Price + discount + "Shop Now"
```

## Finance / Fintech

**Key prompt elements:**
- Professional palette (navy, green, white)
- Data-heavy (charts, numbers, trends)
- Counting number animations
- Trust signals (security icons, compliance badges)
- Conservative animations (smooth, not bouncy)

**Scene pattern:**
```
Hook: Impressive metric ("Save $X,000/year")
Context: Problem with current solutions
Solution: Product with dashboard screenshot
Data: Key metrics with chart animations
CTA: "Get started" + security assurance
```

## Real Estate

**Key prompt elements:**
- Warm, luxurious palette (gold, cream, navy)
- Serif fonts (Playfair Display) for elegance
- Ken Burns photo animations (slow zoom + pan)
- Property stats (bed/bath/sqft/price)
- Agent branding + contact info

**Scene pattern:**
```
Hero: Exterior photo with address overlay
Stats: Price + bed/bath/sqft cards
Tour: 3-5 interior photos with room labels
Details: Key features list (granite, hardwood, etc.)
CTA: Agent name + phone + "Schedule Tour"
```

## Education / EdTech

**Key prompt elements:**
- Warm, inviting colors (not aggressive)
- Clear typography (large, readable)
- Step-by-step progression
- Diagram/illustration animations
- Slower pace (4-8s per scene)

**Scene pattern:**
```
Hook: Question ("Did you know...?")
Concept: Visual explanation (diagram builds)
Steps: 3-5 steps with icons + text
Summary: Key takeaway card
CTA: "Start learning" / "Enroll now"
```

## Healthcare / Wellness

**Key prompt elements:**
- Calming palette (teal, soft blue, white, green)
- Rounded fonts (Nunito, Quicksand)
- Gentle animations (slow fades, gentle springs)
- Trust elements (certifications, doctor quotes)
- Accessibility considerations (high contrast text)

**Scene pattern:**
```
Hook: Relatable health concern
Solution: Product/service introduction
Benefits: 3 key benefits with soothing icons
Trust: Professional endorsement or certification
CTA: "Book a consultation" / "Learn more"
```

## Events / Conferences

**Key prompt elements:**
- Event brand colors and logo
- Dramatic animations (energetic springs)
- Speaker photos (circle mask)
- Date/location prominently displayed
- Countdown elements

**Scene pattern:**
```
Hook: Event name — dramatic reveal
Details: Date + Location + Theme
Speakers: Headshot grid (stagger entrance)
Highlights: Key topics or activities
CTA: "Register Now" + early bird pricing
```

## Personal Brand / Creator

**Key prompt elements:**
- Personality-driven colors and fonts
- Photo/avatar of the creator
- Social handles (@username)
- Engagement CTAs ("Follow", "Subscribe")
- Authentic, less corporate feel

**Scene pattern:**
```
Hook: Bold opinion or value proposition
Content: 3 key points or tips
Personal: Creator photo + name + handle
CTA: "Follow for more" + social icons
```

## Agency / Service Business

**Key prompt elements:**
- Portfolio/case study screenshots
- Before/after comparisons
- Client logos (trust grid)
- Results metrics (ROI, growth %)
- "Book a call" CTA

**Scene pattern:**
```
Hook: Impressive client result
Problem: Common pain point for target audience
Solution: Service description with process visual
Proof: 3 client logos + key result metric
CTA: "Book a free strategy call"
```

## Crypto / Web3

**Key prompt elements:**
- Dark backgrounds, neon accents (#00ff87, #00d4ff)
- Futuristic fonts (Space Grotesk, Orbitron)
- Particle/noise effects for backgrounds
- Token metrics (price, volume, TVL)
- Fast-paced, dynamic animations

**Scene pattern:**
```
Hook: Token/project name with glow effect
Value prop: Key innovation (1 sentence)
Metrics: TVL, holders, transactions (counting)
Ecosystem: Partner logos or integrations
CTA: "Join the community" + social links
```
