# E-commerce & Real Estate Video Prompts

Guidance for product showcases, property tours, listing videos, catalog animations, and commercial videos.

## E-commerce Video Types

### Product Showcase (15-30s)
```
Scene 1 (3s): Product name + hero image (spring entrance)
Scene 2 (5s): Feature 1 — close-up with text overlay
Scene 3 (5s): Feature 2 — different angle
Scene 4 (5s): Feature 3 — in-context usage
Scene 5 (3s): Price + "Shop Now" CTA
```

### Product Catalog (30-60s)
```
Multiple products shown sequentially (3-5s each):
  - Product image with zoom/pan animation
  - Name + price overlay
  - Quick transition (slide or fade)
Final: Brand logo + "View collection" CTA
```

### Sale/Promotion Video (15s)
```
Scene 1 (3s): "SALE" — bold, large, spring bounce, bright color
Scene 2 (5s): Discount percentage (counting animation) + product grid
Scene 3 (4s): "Limited time" urgency text + product highlights
Scene 4 (3s): "Shop Now" + code/URL
```

## Real Estate Video Types

### Property Tour (30-60s)
```
Scene 1 (3s): Address + price as elegant text
Scene 2-N (5-8s each): Room/area photos with:
  - Slow zoom (ken burns) effect
  - Room label overlay (fade in/out)
  - Key details (sqft, features)
Final (5s): Agent info + contact CTA
```

### Listing Highlight (15s)
```
Scene 1 (3s): Hero exterior photo with address
Scene 2 (3s): Price + key stats (bed/bath/sqft)
Scene 3 (6s): 3 interior photos rapid sequence
Scene 4 (3s): Agent branding + "Schedule Tour"
```

## Style Guidelines

### E-commerce
- Clean white or light backgrounds for products
- High contrast for prices and CTAs
- Urgency colors (red, orange) for sales
- Product images: large, centered, well-lit

### Real Estate
- Elegant, warm tones (gold, cream, navy)
- Serif fonts for luxury (Playfair Display)
- Sans-serif for modern (Inter, Montserrat)
- Slow, smooth animations (gentle spring or linear ease)
- Ken Burns effect on property photos (slow zoom + pan)
