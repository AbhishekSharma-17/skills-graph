# Education & Explainer Video Prompts

Guidance for tutorials, course content, concept explanations, code walkthroughs, and how-to videos.

## Common Education Video Structures

### Structure 1: Concept Explainer (60-120s)
```
Scene 1 (3s): Topic title + hook question
Scene 2 (10s): Problem/context setup
Scene 3 (30-60s): Step-by-step explanation (3-5 steps)
Scene 4 (10s): Summary/recap
Scene 5 (5s): Next steps / CTA
```

### Structure 2: Code Walkthrough (30-90s)
```
Scene 1 (3s): "How to [task] in [language]"
Scene 2-N (5-10s each): Code block with highlight + explanation
Final scene (3s): Complete code summary
```

### Structure 3: Step-by-Step Tutorial (60-120s)
```
Per step:
  - Step number + title (spring entrance)
  - Visual demonstration (screenshot/diagram)
  - Key text overlay (fade in)
  - Transition to next step (slide)
```

## Education-Specific Style Guidelines

| Aspect | Recommendation |
|--------|---------------|
| Pace | Slower than marketing (4-8s per scene) |
| Animation | Gentle, supportive — not distracting |
| Text size | Larger (for mobile viewing) |
| Colors | Calm palette — avoid aggressive neons |
| Transitions | Consistent direction (always slide-left for progression) |
| Font | High readability (Inter, Nunito, Open Sans) |

## Code Animation Pattern

```
Background: Dark (#1e1e2e or VS Code theme)
Font: JetBrains Mono or Fira Code, 24-28px
Highlight: Yellow background (#fef08a20) on active line
Line appearance: Typewriter or fade-in, 3-5 frames per line
Comment style: Dimmed (#6b7280) with // prefix
```

## Diagram Animation Pattern

```
Elements appear in logical order:
1. Base structure (boxes, lines) — fade in
2. Labels — slide in from nearest edge
3. Connections/arrows — draw animation (path reveal)
4. Highlights — pulse or color change on key elements
5. Annotations — fade in near relevant element
```
